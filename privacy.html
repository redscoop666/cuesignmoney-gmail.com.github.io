1. 적용 대상

이 방침은 CUESIGN 운영자가 자신의 유튜브 채널(큐사인 뉴스·코인 등)에 영상을 올리기 위해 사용하는 비공개 프로그램 "CUESIGN Publisher"에 적용됩니다. 이 프로그램은 일반 이용자에게 제공되지 않으며, 운영자 본인 계정만 사용합니다.

2. YouTube API 서비스 사용

CUESIGN Publisher는 YouTube API 서비스를 사용합니다. 프로그램을 사용하는 것은 YouTube 서비스 약관에 동의하는 것이며, Google의 데이터 처리는 Google 개인정보처리방침을 따릅니다.

3. 접근·사용하는 정보

  • 운영자 본인 구글 계정의 OAuth 인증 토큰 (권한: 영상 업로드, 채널 정보 읽기)
  • 운영자 채널의 기본 정보(채널 이름·ID) — 올바른 채널에 올리는지 확인하는 용도
  • 이 프로그램이 직접 올린 영상의 ID·주소 — 중복 업로드 방지 용도

다른 이용자나 다른 채널의 개인정보는 수집·저장하지 않습니다. 댓글·구독·평가 등 자동 활동을 하지 않습니다.

4. 저장과 공유

인증 토큰과 업로드 기록은 운영자의 개인 컴퓨터에만 저장되며, Google의 인증·API 서버 외에는 어디에도 전송하거나 제3자와 공유하지 않습니다.

5. 보관 기간과 삭제

토큰은 운영자가 접근 권한을 해제하면 더 이상 사용되지 않으며, 프로그램에서 즉시 삭제합니다. 업로드 기록은 해당 영상이 채널에 있는 동안만 보관합니다.

6. 접근 권한 해제

언제든지 Google 계정 → 보안 → 서드파티 앱 접근에서 CUESIGN Publisher의 접근 권한을 해제할 수 있습니다.

CUESIGN Privacy Policy

Effective date: [2026-10-__]
Operator: CUESIGN ([operator name]) · Contact: [contact email]

1. Scope

This policy applies to "CUESIGN Publisher", a private tool used solely by the operator of the CUESIGN YouTube channels to upload videos to those channels. It is not offered to the public; only the operator's own account uses it.

2. Use of YouTube API Services

CUESIGN Publisher uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is governed by the Google Privacy Policy.

3. Information accessed

  • OAuth tokens for the operator's own Google account (scopes: video upload, read channel info)
  • Basic info of the operator's channel (name, ID), to confirm the upload target
  • IDs/URLs of videos uploaded by this tool, to prevent duplicate uploads

No personal data of other users or channels is collected or stored. The tool performs no automated comments, subscriptions, or ratings.

4. Storage and sharing

Tokens and upload records are stored only on the operator's personal computer and are never transmitted to or shared with anyone other than Google's authentication and API servers.

5. Retention and deletion

Tokens are deleted from the tool immediately when access is revoked. Upload records are kept only while the corresponding video remains on the channel.

6. Revoking access

Access can be revoked at any time at Google Account → Security → Third-party access.
